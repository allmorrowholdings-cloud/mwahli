# MWAHLI

MWAHLI is a platform for making personal gifts from words, memories, and drawings. Its three free Studio tools work in a browser on a phone or computer.

## Studio

- **Memory Jar** holds four memories behind coloured hearts or animal portraits. Each memory can include a message, photo, GIF, or video. The sender decides whether the recipient can open one memory or two.
- **Love Letter / Poem** pairs a letter or poem with a choice of five stationery designs. Writers can add a closing, sign by name or anonymously, and download the finished piece as a PNG. A shared link lets the recipient read it or listen using their browser’s voice.
- **Art4U** is a freehand drawing canvas with adjustable brush sizes and colours for creating personal artwork.

## Gifts and occasions

Moments keeps track of meaningful dates. Capsule schedules messages for a future occasion. Gifts and Local bring together gift browsing and local delivery, while Creators connects customers with artists for commissioned pieces.
