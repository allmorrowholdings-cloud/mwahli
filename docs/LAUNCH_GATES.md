# Public Launch Gates

Do not call MWAHLI publicly launch-ready until every applicable gate is closed with evidence.

| Gate | Evidence required |
|---|---|
| Brand | Name, domain and trademark clearance in target markets |
| Legal | Approved Terms, Privacy, recipient safety, marketplace, creator rights, returns, minors and scheduled-message rules |
| Identity | Recovery, consent history, export/delete, block/no-contact flows; admin MFA |
| Studio safety | Private media, malware scanning, moderation, intimate-media policy, abuse reporting |
| Money | Live providers, verified webhooks, reconciliation, refunds, contributions, payouts and chargebacks |
| Delivery | First-city merchant/courier agreements, substitution rules, recipient privacy and escalation owner |
| AI | Grounding tests, privacy controls, evals, spend limits and safe no-AI fallback |
| Operations | Support, Trust & Safety, money reconciliation and delivery escalation staffing |
| Security | External pen test, SAST/DAST, dependency/secret scanning, incident response and access review |
| Resilience | Backup/restore drill and scheduled-message/capsule recovery drill |
| Quality | E2E digital-only, physical, group, creator, exchange, care and capsule flows |

## Recommended release wedge

1. Studio: Memory Jar, Love Letter, Art4U, Poem, Playlist links, Cards, Timeline, Open When and Capsule.
2. People + Moments + Keeps + Gift ID + Surprise.
3. One-city local gifts and same/next-day fulfilment.
4. Together + curated creators.
5. Care and Work after reliability is proven.
